# 🛒 E-commerce de Banfield

Proyecto de desarrollo web para un sistema de comercio electrónico (E-commerce) enfocado en la gestión de productos, ventas y control de empleados[cite: 1].

## 🚀 Tecnologías Utilizadas
El proyecto está desarrollado utilizando las siguientes tecnologías y herramientas:
* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Diseño y Prototipado:** Figma[cite: 1] (utilizado para el boceto de la interfaz y la estructura visual)
* **Control de Versiones:** Git / GitHub

---

## 📋 Requisitos Funcionales del Sistema

### A. Autenticación y Módulos de Empleados
* **Login de usuarios**.
* **ABM (Alta, Baja y Modificación) de empleados.
* **Gestión de roles:** 
  * Gerente
  * Administrativo
  * Cajero/a
  * Repositor/a

### B. ABM de Productos y Catálogo
* Gestión de información de artículos:
  * Imagen
  * Nombre y descripción
  * Precios: Precio neto, IVA, Precio público y Gestión de descuentos
  * Control de stock

### C. Tienda (Vista Cliente)
* **Catálogo dinámico**.
* **Buscador y filtros** avanzados.
* **Carrito de compras**.
* **Proceso de confirmación de pedido**.

### D. Reportes y Listados de Ventas
* **Listado general de ventas:** .
* **Facturación y reportes estadísticos:**
  * Diario
  * Semanal
  * Mensual
  * Anual
